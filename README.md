# 🧠 Sentence Builder Quiz App

A modern and responsive sentence builder quiz application built with **Vite + React + TypeScript**, styled using **Vanilla CSS** to match a clean Figma design.

## ✨ Features

- 📝 Interactive fill-in-the-blank sentence questions
- ⏱️ Countdown timer for each question
- 🎯 Immediate result calculation and feedback
- 📱 Fully responsive design based on a custom Figma prototype
- 💡 Clean, readable and maintainable code using React hooks and component structure

---

## 🛠️ Tech Stack

- **Frontend**: Vite + React + TypeScript
- **Styling**: Vanilla CSS (converted from Tailwind)
- **Routing**: React Router
- **API**: Axios for fetching questions
